# Kahve Fincanı Dolma Draması

Bu proje, insanlığın en büyük sorununu çözmeyi amaçlar: **Kahve fincanı neden hiç dolmuyor?**

## Ne Yapar?

Hiçbir şey. Ama çok ciddi bir şekilde hiçbir şey yapmaz.

Python kodu çalıştığında, kahve fincanının dolma sürecini adım adım, dramatik seslerle ve gereksiz detaylarla anlatır. Asla bitmez. Çünkü kahve bitmez, hayat bitmez, bu simülasyon da bitmez.

## Nasıl Çalıştırılır?

```bash
python kahve.py
```

Sonra otur ve izle. Kahve dolacak. Ya da dolmayacak. Belki de sen dolacaksın.

## Özellikler

- %100 gerçekçi kahve fiziği (yalan)
- Dramatik bekleme süreleri
- Türkçe absürt yorumlar
- Sonsuz döngü garantisi
- Bürokrasi simülasyonu içerir (gizli)
